# Mi Proyecto Web

## Descripción

Este proyecto consiste en una página web desarrollada utilizando HTML y CSS.

El objetivo del proyecto es aprender a utilizar Git y GitHub para controlar
versiones y trabajar de manera colaborativa.

## Tecnologías utilizadas

- HTML
- CSS
- Git
- GitHub

## Archivos del proyecto

- `index.html`: página principal.
- `contacto.html`: página de contacto.
- `estilos.css`: estilos de la página.
- `README.md`: documentación del proyecto.

## Ramas utilizadas

El proyecto cuenta con tres ramas:

- `main`: versión principal.
- `desarrollo`: desarrollo de nuevas funcionalidades.
- `contacto`: desarrollo de la página de contacto.
